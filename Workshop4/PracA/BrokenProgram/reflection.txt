1. Of all the values in the items list, only one of them was wrong. Which value was incorrect? Why were all the other values still correct?
Answer: One value in the items list became incorrect because the code used Substring() with fixed character positions. Since the numbers in the input have different lengths, the code did not always read the correct characters. The other values were correct because their positions happened to match what the code expected.

2. What was going wrong when iterating through the symbols list?
Answer: The symbols list had extra spaces. Because of that, "*" was not always read exactly as "*". I fixed this by using .Trim().

3. How did stepping through the code and using the debugger help you find the issues?
Answer: The debugger helped me see the program run step by step. I could watch 'total', 'i', and 'value' change, so it was easier for me to see where the program started doing the wrong thing.
